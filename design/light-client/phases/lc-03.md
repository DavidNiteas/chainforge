# LC-03：MPT 状态证明验证

## 目标

实现 Merkle Patricia Trie（MPT）证明验证，使轻客户端能够验证账户状态。

## 交付物

- `mpt.rs` — MPT 节点解码、路径解析、证明验证
- `MptProof` — 证明封装结构
- `verify_proof(root, key, proof_nodes)` — 核心验证函数

## 验收标准

- [x] Leaf / Extension / Branch 节点解码正确
- [x] 路径编码（compact hex）解析正确
- [x] 完整证明验证流程测试覆盖
- [x] 全 workspace 测试通过
