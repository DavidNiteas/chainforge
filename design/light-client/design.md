# 轻客户端（Light Client）设计

## 目标

实现只同步区块头、不存储完整状态的轻客户端，使资源受限设备（手机、浏览器）能够验证交易和状态证明。

## 核心功能

- 仅同步 BlockHeader 链
- 通过 Merkle Patricia Trie 证明验证账户状态
- 通过 MerkleProof 验证交易包含
- SPV（简单支付验证）风格的安全模型

## 迭代阶段

| 阶段 | 目标 |
|------|------|
| LC-01 | 区块头同步与验证 |
| LC-02 | MerkleProof 交易验证 |
| LC-03 | MPT 状态证明验证 |
| LC-04 | 与全节点的 P2P 协议扩展 |
