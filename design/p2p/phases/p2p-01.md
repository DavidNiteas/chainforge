# P2P-01: 基础 TCP 连接 + Noise 握手

## 目标

建立两个 Kilnchain 节点之间的加密通信通道。实现 PeerId 标识、基于 Noise 协议的握手认证、以及基础的心跳保活机制。

## 核心代码规格

### PeerId

```rust
pub struct PeerId([u8; 32]); // keccak256(公钥)

impl PeerId {
    pub fn from_public_key(pk: &[u8]) -> Self {
        PeerId(keccak256(pk))
    }
}
```

### Noise 握手

```rust
pub struct NoiseTransport {
    static_key: [u8; 32],
}

impl NoiseTransport {
    /// 作为发起者进行 XX 握手
    pub async fn dial(&self, addr: SocketAddr) -> Result<NoiseStream, Error>;
    
    /// 作为响应者接受握手
    pub async fn listen(&self, bind: SocketAddr) -> Result<NoiseStream, Error>;
}
```

### 心跳

```rust
pub async fn heartbeat(mut stream: NoiseStream, interval: Duration) {
    loop {
        tokio::time::sleep(interval).await;
        stream.send(Message::Ping).await?;
        // 等待 Pong，超时则断开
    }
}
```
